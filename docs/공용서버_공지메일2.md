이전 메일로 전달드렸듯이 현재 공용 서버의 루트 파티션(/) 용량이 포화 상태에 가까워져 연구 환경의 안정성이 우려되고 있습니다. 원활한 연구 진행을 위해 아래와 같이 계정별 데이터 정리 및 향후 관리 지침을 안내드리오니, 내용을 확인하시어 기한 내 조치를 부탁드립니다.

1. 계정별 데이터 정리 요청 (기한: 이번 주 금요일까지)
현재 `/home` 경로 내 사용량이 많은 아래 계정 소유자분들께서는 사용 용량을 100GB 이하로 줄여주시길 부탁드립니다.

대상 계정: `/home/chlduswns99`, `/home/sunga`, `/home/dongkuk`, `/home/seyeon`
용량 확보에 기술적인 어려움이나 이슈가 있는 경우 미리 공유해 주시기 바랍니다.
2. 장기 미사용 계정 삭제 예고 (일정: 차주 중)
장기간 사용되지 않아 관리가 되지 않는 아래 계정들은 서버 효율화를 위해 다음 주에 일괄 삭제될 예정입니다. 보관이 필요한 데이터가 있다면 삭제 전 백업하시기 바라며, 이슈가 있을 시 말씀해 주세요.

대상 경로: `/home/dada09`, `/home/aaai`, `/mnt/nvme02/home/dada09`
그 외 다른 디스크에 분산되어 있는 계정들도 필요성 여부를 확인하여 순차적으로 정리할 예정입니다.
3. 향후 공용 서버 관리 지침 (신규)
앞으로의 쾌적한 연구 환경을 위해 아래와 같은 관리 규칙을 적용하고자 합니다. 개선안이 있다면 언제든 의견 공유 부탁드립니다.

계정 생성 및 용량 제한: 신규 계정은 `/home`에 생성하여 일괄 관리하며, 계정별 기본 용량은 최대 100GB로 제한합니다.
대용량 데이터 관리: 실험 시 발생하는 대용량 데이터는 `/home`이 아닌 별도의 디스크(`/mnt`)에서 관리해 주시기 바랍니다.
[서버 활용 가이드: 가상환경 및 캐시 설정] (민경님이 공유해주신 팁을 바탕으로 정리하였습니다)
① 가상환경 생성 ( `/mnt` 활용) conda 가상환경 생성 시 `/home` 용량을 차지하지 않도록 아래와 같이 경로를 지정해 주세요.

`conda create -p /mnt/nvme03/{계정명}/envs/{가상환경명}`
`conda activate /mnt/nvme03/{계정명}/envs/{가상환경명}`
② 캐시 저장 위치 변경 (권장) 기본적으로 ~/.cache에 저장되는 라이브러리 캐시를 `/mnt`로 변경하면 용량 관리가 수월합니다. 아래 내용을 `~/.bashrc`에 추가하여 사용해 주세요.

`export HF_HOME=/mnt/nvme03/{계정명}/.cache/huggingface`
`export TORCH_HOME=/mnt/nvme03/{계정명}/.cache/torch`
`export PIP_CACHE_DIR=/mnt/nvme03/{계정명}/.cache/pip`
③ 데이터 및 결과물 저장 아래 항목들은 반드시 `/mnt/nvme03/{계정명}/` 하위 경로에 저장해 주시기 바랍니다.
