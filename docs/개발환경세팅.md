- 계정 생성 및 권한 부여
  - (기존 가이드와 동일)
- [리눅스 Anaconda 설치 사이트](https://www.anaconda.com/docs/getting-started/anaconda/install/linux-install#wget)
- CUDA 환경변수 설정
  - 12.8 버전을 내 계정의 기본 CUDA로 지정
  - `echo 'export PATH=/usr/local/cuda-12.8/bin:$PATH' >> ~/.bashrc`
  - `echo 'export LD_LIBRARY_PATH=/usr/local/cuda-12.8/lib64:$LD_LIBRARY_PATH' >> ~/.bashrc`
  - `source ~/.bashrc`
- CUDNN 확인
  - `cat /usr/local/cuda-12.8/include/cudnn_version.h | grep CUDNN_MAJOR -A 2`
- 가상환경 생성
  - `python=3.11.10`
- [CUDA 전용 PyTorch 다운로드 사이트]( https://pytorch.org/get-started/locally/?__hstc=76629258.724dacd2270c1ae797f3a62ecd655d50.1746547368336.1746547368336.1746547368336.1&__hssc=76629258.9.1746547368336&__hsfp=2230748894)
- editor 연결 및 host 추가
  - Host {호스트명 지정}
  - HostName {호스트 IP 주소}
  - User {사용자 계정 id}
