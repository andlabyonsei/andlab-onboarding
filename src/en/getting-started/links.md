## School & Network

| Name | Purpose | Link |
|------|------|------|
| IT Services IP request | Request a static IP or server IP (Korean) | [yis.yonsei.ac.kr](https://yis.yonsei.ac.kr/ics/service/ipApply.do) |
| Yonsei VPN request | Access the campus network from off campus (Korean) | [yis.yonsei.ac.kr](https://yis.yonsei.ac.kr/ics/service/PolicyApplyInfo.do) |

::: info
To SSH into the shared servers from off campus, you usually need a **VPN connection**. Request VPN access first, right after you join.
:::
