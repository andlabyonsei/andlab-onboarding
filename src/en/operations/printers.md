# Printer Setup

IP addresses of the printers used at ANDlab. Add them while connected to the same network (VPN or campus network).

## Printers

| Type | Use | IP address |
|------|------|---------|
| Standard printer | Regular printing | `165.132.192.240` |
| HP color printer | Color printing | `165.132.193.44` |


## Adding on macOS

1. **System Settings** → **Printers & Scanners**
2. **Add Printer, Scanner, or Fax** (+)
3. Select the **IP** tab
4. Enter one of the IPs above as the address
5. Protocol: **IPP** or **HP Jetdirect - Socket** (whichever fits the printer)
6. Driver: auto-detect or install the manufacturer's driver


## Adding on Windows

1. **Settings** → **Bluetooth & devices** → **Printers & scanners**
2. **Add a printer or scanner**
3. **The printer that I want isn't listed** → add manually by IP address
4. Enter one of the IPs above and install the driver
