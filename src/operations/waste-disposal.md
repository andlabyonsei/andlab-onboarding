# 랩실 폐기물 처리

랩실에서 물품을 폐기할 때의 절차입니다.

폐기 전에 **비품 스티커(학교물품 여부)** 를 먼저 확인하세요. 스티커 유무에 따라 처리 방법이 달라집니다.

## 처리 방법 요약

| 구분 | 조건 | 처리 방법 |
|------|------|-----------|
| 학교 물품 | 비품 스티커 부착 | 행정실 메일(`gsi@yonsei.ac.kr`)로 사진 공유 후 안내 대기 |
| 일반 물품 | 비품 스티커 없음 | 랩실 내에서 직접 처리 (교내 폐기업체 이용 가능) |


## 1. 비품 스티커가 부착된 물품 (학교물품)

학교 비품으로 등록된 물품은 임의로 폐기할 수 없습니다.

1. 물품별로 아래 사진을 준비합니다.
   - **비품 스티커** 사진
   - **물품 전체** 샷
2. **행정실 메일(`gsi@yonsei.ac.kr`)** 로 물품별 사진을 공유합니다.
3. 행정실 안내에 따라 이후 절차를 진행합니다.

::: warning
비품 스티커가 있는 물품은 행정실 확인 없이 직접 폐기하지 마세요.
:::


## 2. 비품 스티커가 없는 물품

비품 스티커가 없으면 **랩실 내에서 직접 처리**하면 됩니다.  
대형·다량 폐기 등이 필요하면 아래 교내 폐기업체를 이용하세요.

### 업체 정보

| 항목 | 내용 |
|------|------|
| 업체 | (주) 복천 (학교 상주업체) |
| 근무시간 | 오전 6시 ~ 오후 3시 |

::: tip
업체 연락처 등 상세 정보는 [시설수리·폐기요청·불용신청 안내](https://chemeng.yonsei.ac.kr/?c=211&s=211&gp=1&gbn=viewok&ix=2863)에서 확인할 수 있습니다.
:::

### 폐기 요청 절차

1. **문자로 작업 요청**을 보냅니다. 아래 내용을 포함하세요.
   - **요청인 정보**: 이름, 메일 주소, 연락처
   - **소속 정보**: 캠퍼스 내 건물명, 연구실 호수
   - **폐기물품 리스트** (이미지 첨부)
   - **희망 일정**
   - 필요 시 **문의사항** (분해·외부 이동 여부 등)
2. 담당자가 **비용**과 **가능한 일정**을 회신합니다.
3. 일정·비용이 확정되면 안내에 따라 폐기 작업을 진행합니다.

::: info
교내 모든 폐기 작업을 담당하기 때문에 **희망 일정보다 지연될 수 있습니다.** 여유를 두고 요청하세요.
:::
