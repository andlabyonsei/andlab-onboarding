# 프린터 설정

ANDlab에서 사용하는 프린터 IP 주소입니다. 같은 네트워크(VPN 또는 학교망)에 연결된 상태에서 추가합니다.

## 프린터 목록

| 종류 | 용도 | IP 주소 |
|------|------|---------|
| 일반 프린터 | 기본 인쇄 | `165.132.192.240` |
| HP 컬러 프린터 | 컬러 인쇄 | `165.132.193.44` |


## macOS에서 추가

1. **시스템 설정** → **프린터 및 스캐너**
2. **프린터 또는 스캐너 추가** (+)
3. **IP** 탭 선택
4. 주소에 위 IP 입력
5. 프로토콜: **IPP** 또는 **HP Jetdirect - Socket** (프린터에 맞게 선택)
6. 드라이버: 자동 감지 또는 제조사 드라이버 설치


## Windows에서 추가

1. **설정** → **블루투스 및 장치** → **프린터 및 스캐너**
2. **프린터 또는 스캐너 추가**
3. **원하는 프린터가 목록에 없음** → IP 주소로 수동 추가
4. 위 IP 입력 후 드라이버 설치
