# 연구간접비 물품 구매

연구간접비(지능형혁신연구소 간접비)로 랩실 물품을 구매하는 절차와, 구매 후 **증빙 자료를 언제·어떻게 담당자에게 전달하는지** 정리했습니다.

::: info 연구소 행정 담당자 (2026.09.01~)
**배유림 선생님** — [byr@yonsei.ac.kr](mailto:byr@yonsei.ac.kr)

연구간접비 사용 가능 여부 확인, 결제 증빙 제출, 정산 문의는 모두 이 담당자에게 합니다.
:::

## 한눈에 보기

| 단계 | 할 일 | 시점 |
|------|-------|------|
| 1. 사전 확인 | **지도교수님과 상의**해 승인을 받은 뒤, 품목·금액·용도를 담당자에게 보내 **집행 가능 여부·비품 해당 여부·남은 한도·사용 기한** 확인 | 결제 **전** |
| 2. 주문·결제 | 담당자에게 **공용카드·ISP USB**를 받아 **백양관 재무회계팀 PC**에서 결제 (평일) | 확인 후 |
| 3. 수령·사진 촬영 | 물품별 사진 **2장씩** 촬영 | 물품 도착 직후 |
| 4. 증빙 제출 | **영수증 + 물품 사진을 한 번에** 담당자에게 메일 전송, **납품증빙서류**를 작성해 교수님께 전달 | 물품 수령 후 |


## 1. 구매 전 확인

### 지도교수님과 상의

연구간접비는 교수님 예산이므로, 구매하려는 **품목·수량·대략적인 금액과 필요한 이유**를 먼저 **지도교수님과 상의해 승인**을 받습니다. 승인을 받은 뒤 아래 내용을 확인하고 담당자에게 문의하세요.

### 사용 가능한 용도

연구소 간접비는 연구소 운영 및 연구·학술활동 지원 예산입니다.

- 연구소 운영비, 공간 유지 관련 비용
- 논문게재료, 국제화경비, 영문교정료
- 사무용품 및 공용 물품

특정 연구실의 **개별 연구과제용 장비·물품**이나 **개인 용도 물품**은 집행이 어려울 수 있습니다.

### 비품 구매 한도

비품은 간접비 잔액과 **별도로** 연구처가 정한 범용성 비품 구입 한도 안에서만 살 수 있습니다.

- 비품 한도는 연구소 소속 교수님들이 **함께 쓰는 연구소 전체 한도**이며, 연구소에서 교수님별 구입 가능 금액을 기준으로 관리합니다.
- 간접비 잔액이 충분해도 비품에는 이 한도가 따로 적용됩니다.
- 비품은 연구소 구성원이 **공동으로 쓸 수 있는 범용성 물품**이어야 합니다.
- 한도 금액은 배정액에 따라 **매번 달라지므로**, 구매 전에 담당자에게 현재 남은 한도를 확인하세요.

### 사용 기한

간접비 사용 기한과 이월 가능 여부는 **회계연도·배정 시기에 따라 달라집니다.** 구매 전에 담당자에게 현재 예산의 사용 기한을 확인하세요.

::: warning 결제 전 반드시 확인
비품 구매는 예산전용·비품등록 등 사전 절차가 필요할 수 있습니다. **결제 전에** 담당자에게 **구매 품목, 금액, 사용 용도**를 메일로 보내 비품 해당 여부, 남은 구입 가능 한도, 사용 기한을 확인한 뒤 진행하세요.
:::


## 2. 주문·결제

- **연구소 공용카드(법인카드)** 사용을 권장합니다. 주임교수님 법인카드로 결제하는 것도 가능하지만, 이 경우 부서대체 처리가 추가로 필요합니다. ([아래 참고](#주임교수님-법인카드로-결제한-경우))
- **주말·공휴일 사용은 지양**합니다. 부득이하게 사용했다면 **10자 이내의 사용 사유**를 함께 전달합니다.
- 데스크톱처럼 부품이 포함된 물품은 담당자 안내에 따라 **SSD·RAM 등 부품을 소모품으로 분류해 본체와 별도로 주문**할 수 있습니다. 주문 방식은 사전 확인 단계에서 담당자와 정하세요.

### 연구소 공용카드로 결제하는 방법

공용카드는 온라인 결제 시 **ISP 인증서(USB)** 가 필요하며, 결제는 [**백양관 재무회계팀**](https://www.yonsei.ac.kr/sc/359/subview.do?enc=Zm5jdDF8QEB8JTJGY3JkTG5rJTJGc2MlMkYxNiUyRjMxJTJGdmlldy5kbyUzRg%3D%3D) PC에서 직접 진행합니다.

1. 담당자에게 연락하여 **공용카드와 ISP USB**를 받습니다.
2. 연세대학교 재무회계팀으로 찾아갑니다. 재무회계팀은 **오전 9시부터** 근무하므로 그 이후에 방문하세요.
3. 재무회계팀 **PC에서 직접** 주문·결제합니다.
4. 결제가 끝나면 카드와 ISP USB를 담당자에게 돌려드립니다.

::: tip
재무회계팀 PC에서 바로 결제할 수 있도록, 방문 전에 **주문할 상품 링크·수량·배송지**를 미리 정리해 가세요.
:::


## 3. 물품 수령 후 사진 촬영

정산을 위해 **물품마다 사진 2장**이 필요합니다.

| 상황 | 촬영 방법 |
|------|-----------|
| 기본 | **박스 사진 1장 + 물품 사진 1장** |
| 박스 사진이 없을 때 | 물품을 **다른 각도로 2장** |
| 같은 물품 여러 개 | 한 사진에 **모두 나오도록** 촬영 (예: 모니터 2대, 의자 3개) |
| 세트 물품 | 세트별로 각각 촬영 |
| 본체에 장착된 SSD·RAM | 본체 사진으로는 증빙이 어려움 → **케이스 커버를 열고 장착된 부품 근접 사진** |

::: tip
SSD·RAM을 따로 주문해도 본체에 장착된 상태로 배송될 수 있습니다. 조립·설치 전에 박스와 부품 사진을 먼저 찍어 두면 나중에 케이스를 다시 열 필요가 없습니다.
:::


## 4. 증빙 자료 제출

물품을 받은 뒤 **영수증과 물품 사진을 한 메일에 함께** 담당자에게 보냅니다. 이와 별도로 **납품증빙서류를 작성해 교수님께 전달**합니다.

### 교수님께 납품증빙서류 전달

물품을 받으면 **납품증빙서류**를 작성해 **지도교수님께 전달**합니다. 아래 양식을 내려받아 작성하세요. 작성 방법이 헷갈리면 담당자에게 확인하세요.

| 양식 | 다운로드 |
|------|----------|
| 납품증빙서류 양식 (교수님 전달용) | <a href="/docs/purchasing/delivery-proof-form.hwp" download="납품증빙서류_양식.hwp">HWP 다운로드</a> |

### 제출 자료

| 자료 | 비고 |
|------|------|
| 카드 영수증 | 법인카드 결제 영수증 |
| 거래명세서 / 구매 영수증 | 판매처에서 발급 |
| 주문 상세 내역 화면 | **네이버 등 온라인 구매 시** 주문상세정보(상품명, 결제금액, 결제수단이 보이는 화면)를 PDF·캡처로 첨부 |
| 물품 사진 | 물품별 2장 (위 3단계 기준) |
| 주말·공휴일 사용 사유 | 해당 시, 10자 이내 |

여러 파일은 압축(zip)해서 첨부하면 편합니다.

### 메일 예시

```
받는 사람: 배유림 선생님 (byr@yonsei.ac.kr)
제목: [ANDlab] MM/DD 결제 건 증빙 자료 전달드립니다.

배유림 선생님, 안녕하세요. 정보대학원 장백철 교수님 ANDlab 연구실의 OOO입니다.
MM/DD에 결제한 건의 증빙을 위해 카드영수증, 구매영수증, 주문상세내역, 물품 사진을 첨부하여 보내드립니다.
(구매 품목: 데스크톱 2대, 모니터 2대 …)
확인하신 뒤, 결제 내역에 문제가 없는지 검토 부탁드립니다.

감사합니다.
```

### 주임교수님 법인카드로 결제한 경우

연구소 예산으로 **부서대체** 처리가 필요합니다. **결제일**과 함께 **카드 영수증·거래명세서**를 담당자에게 전달하면 확인 후 부서대체가 진행됩니다.
