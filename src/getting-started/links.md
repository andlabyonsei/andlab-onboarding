# 참고 링크

랩실 생활과 연구에 자주 쓰는 외부 링크를 모아 두었습니다.

## 학교·네트워크

| 이름 | 용도 | 링크 |
|------|------|------|
| 정보통신처 IP 신청 | 고정 IP·서버 IP 신청 | [yis.yonsei.ac.kr](https://yis.yonsei.ac.kr/ics/service/ipApply.do) |
| Yonsei VPN 신청 | 교외에서 학교 네트워크 접속 | [yis.yonsei.ac.kr](https://yis.yonsei.ac.kr/ics/service/PolicyApplyInfo.do) |

::: info
캠퍼스 외부에서 공용 서버에 SSH로 접속하려면 보통 **VPN 연결**이 필요합니다. 입학·합류 직후 VPN 신청을 먼저 진행하세요.
:::
