# 시작하기

ANDlab에 오신 것을 환영합니다. 이 가이드는 랩실에 처음 합류한 신입생·연구원이 빠르게 적응할 수 있도록 정리한 문서입니다.

## 이 가이드에서 다루는 내용

| 섹션 | 내용 |
|------|------|
| [랩실 출입 방법](./lab-access) | 출입문 열기·잠그기 |
| [참고 링크](./links) | VPN, IP 신청, 공유 시트 등 |
| [공용 서버](../servers/) | SSH, 개발 환경, 리소스 관리 |
| [랩실 운영](../operations/) | 홈페이지, 프린터, 폐기물 처리 |
| [연구·논문](../research/) | KSCI 논문 제출 등 |

## 신입생 체크리스트

랩실에 출근한 뒤 아래 순서대로 진행해 보세요.

- [ ] **랩실 출입** — [출입 방법](./lab-access)을 읽고 학생증으로 출입을 연습합니다.
- [ ] **필수 링크 확인** — [참고 링크](./links)에서 VPN 신청, 공유 시트 등을 북마크합니다.
- [ ] **공용 서버 계정** — 랩장에게 계정 생성을 요청한 뒤 [SSH 접속](../servers/ssh-and-account)을 설정합니다.
- [ ] **개발 환경 세팅** — [환경 세팅](../servers/environment-setup)과 [디스크·캐시 관리](../servers/disk-and-cache)를 따라합니다.
- [ ] **리소스 사용 규칙 숙지** — [리소스 사용 가이드](../servers/resource-usage)를 반드시 읽어 주세요.

## 도움이 필요할 때

- 서버 계정, 권한, 하드웨어 이슈 → 랩장에게 문의
- VPN·학교 네트워크 → [정보통신처](https://yis.yonsei.ac.kr/) 안내 참고
- 가이드 내용 보완이 필요하면 랩장에게 알려 주세요.
