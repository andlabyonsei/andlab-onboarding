# 랩실 출입 방법

ANDlab 출입문은 학생증 태그와 KT 출입 시스템을 함께 사용합니다. 아래 순서를 정확히 따라야 문이 정상적으로 열리고 잠깁니다.

## 처음으로 문을 여는 경우

1. "해제" 버튼을 누른 뒤 **학생증을 리더기에 태그**합니다.
2. 문이 열리면 들어간 뒤, **하얀색 KT 버튼**을 눌러 자동잠금을 비활성화합니다.

::: tip
KT 버튼을 누르지 않으면 그대로 다시 잠기므로 들어온 직후 꼭 눌러 주세요.
:::

## 마지막으로 문을 잠가야 하는 경우

1. **KT 하얀색 버튼**을 먼저 눌러 잠금 장치를 돌출시킵니다.
2. **짧은 시간 안에** 검은색 패드를 누릅니다.
3. 문을 열고 밖으로 나오면 **약 3초 뒤** 문이 자동으로 잠깁니다.
4. "경계" 버튼을 누른 뒤 **학생증을 리더기에 태그**합니다.

::: warning 주의
- 나가기 전 KT 버튼 → 검은색 패드 순서를 지키세요. 순서가 바뀌면 잠금이 되지 않을 수 있습니다.
- 랩실을 마지막으로 나가는 사람은 반드시 위 절차로 문을 잠가 주세요.
:::
